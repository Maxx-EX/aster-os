Aster 星芒

这是一个自己写的浏览器，跑在一个自己写的内核上。点这里走网络重新加载本页

这台机器

  • 架构 ARM64，QEMU virt 或树莓派
  • 内核 Rust + C，无任何现成内核代码
  • 引导器两级：AVP 三级校验 + EX3 指纹
  • 图形：virtio-gpu 2D，双缓冲整帧上屏

这个浏览器能做什么

自己写的 HTML 分词器与块级排版：标题、段落、列表、分隔线、链接、代码。

没有 JavaScript，没有 CSS 层叠，没有图片解码 —— 它只保证一件事： 文字能排整齐、能滚动、链接能点。

试试这些

  • 命令 web 打开本页
  • 命令 web 10.0.2.2:8088/ 拉 QEMU 宿主的页面
  • 命令 http get 10.0.2.2 8088 / 保存成文件

要返回起始页，输入 web home 即可。
